# Python Task Manager

Projeto de estudo: lista de tarefas no terminal, com opções para adicionar, listar, remover e sair. As tarefas ficam em memória e são perdidas ao encerrar.

Execute `python gerenciador.py` com Python 3.11 ou posterior.

Entradas inválidas, índices fora da lista, remoção em lista vazia e fim da entrada são tratados sem encerrar com erro. Testes: `python -m unittest discover -s tests -v`.

## English

A small, in-memory terminal task manager for learning Python. Handles invalid input and empty lists safely. Run `python gerenciador.py`. Tasks are not saved after exiting.

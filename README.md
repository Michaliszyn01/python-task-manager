# Python Task Manager

Projeto de estudo: lista de tarefas no terminal, com opções para adicionar, listar, remover e sair. As tarefas ficam em memória e são perdidas ao encerrar.

Execute `python gerenciador.py` com Python 3.11 ou posterior.

Status desta base: protótipo inicial, ainda sem proteção completa contra entradas inválidas. A melhoria de validação será revisada em pull request próprio.

## English

A small, in-memory terminal task manager for learning Python. This initial prototype still needs input validation. Run `python gerenciador.py`.
